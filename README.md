# Study Buddy demo

Interest-led Year 4-6 maths practice demo. React 19 + TypeScript + Vite + Tailwind 3. Designed with Impeccable (see PRODUCT.md, DESIGN.md).

## Run locally
    npm install
    npm run dev

## Build
    npm run build   # outputs static files to dist/

Passcode for the demo screen: buddy2026 (set in src/screens/onboarding.tsx).
